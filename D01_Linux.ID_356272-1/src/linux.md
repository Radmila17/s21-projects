## Part 8. Установка и базовая настройка сервиса **SSHD**

- ![alt text](image-29.png)
-  установка
- ![alt text](image-30.png)
- добавила автостарт службы при загрузке системы.
- ![alt text](image-31.png)
- Перенастрола службу SSHd на порт 2022. 
- ![alt text](image-28.png)
-  ps - команда для вывода информации о запущенных процессах.
- Ключ -C позволяет указать имя команды (без пути), по которому нужно отфильтровать процессы. То есть ключ -C: позволяет выбрать процессы по имени команды (comm). В данном случае мы указываем имя "sshd"
- ![alt text](image-32.png)
- Перезагрузила систему
- ![alt text](image-33.png)
- Вывод команды netstat -tan содержит \
`tcp 0 0 0.0.0.0:2022 0.0.0.0:* LISTEN`  \
- `-t` (или `--tcp`): Показать TCP-соединения.
- `-a` (или `--all`): Показать все сокеты (как слушающие, так и установленные соединения).
- `-n` (или `--numeric`): Показать числовые адреса (не преобразовывать в имена хостов или служб).
- Таким образом, `netstat -tan` выводит все TCP-соединения в числовом формате.
- tcp. Протокол соединения (в данном случае TCP)

- 0 (Recv-Q).
Размер очереди полученных данных (в байтах), ожидающих обработки.
0 = данные немедленно обрабатываются, проблем нет.

- 0 (Send-Q).
Размер очереди данных, готовых к отправке (в байтах).
0 = данные отправляются немедленно, задержек нет.

- 0.0.0.0:2022 (Local Address).
Локальный адрес и порт, который прослушивает сервер.
0.0.0.0 = сервер ожидает подключения на ВСЕХ сетевых интерфейсах порта  (Wi-Fi/Ethernet/локальная сеть)

- 0.0.0.0:* (Foreign Address)
Адрес и порт удалённых клиентов.
0.0.0.0:* = ожидание подключений от ЛЮБЫХ клиентов (любой IP, любой порт)

- LISTEN (State)
Состояние соединения: сервер ожидает входящих подключений.
